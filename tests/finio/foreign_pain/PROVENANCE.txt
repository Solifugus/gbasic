# READ BEFORE THE ADAPTER WAS WRITTEN. What they established:
#   - this family's revision lives in the NAMESPACE exactly as camt's does
#     (pain.001.001.03), so the same rule serves both and is now shared in
#     stdlib/finio_iso20022.bas;
#   - pain.001 carries NbOfTxs and CtrlSum at TWO levels, per payment block and
#     per message -- which for a file you SEND is not a test oracle but the
#     thing a bank checks before it does anything else;
#   - a pain.008 direct debit is a sibling in the same family and the same
#     namespace scheme, so "is this pain.001" cannot be answered by looking for
#     an ISO 20022 namespace alone.
#
# WHAT THEY DO NOT SUPPLY, and why tools/make_pain001_fixture.py exists: every
# one of them has a SINGLE payment-information block, so its group control sum
# is a copy of the block's rather than a total -- a two-level checksum tested
# only where the two levels are equal tests one level. Nor does any publisher
# ship a scheme violation on purpose.
