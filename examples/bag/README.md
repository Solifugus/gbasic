# BAG: BASIC Adventure Generator

BAG is a small menu-driven adventure game generator written in gBASIC.

It is inspired by classic BASIC adventure generators from the mid-1980s: the user describes an adventure world with areas, exits, items, and triggers, then BAG writes a playable adventure game source file.

## Run

From the repository root:

```sh
./gbasic examples/bag/bag.bas
```

BAG asks whether to load a tiny demo project. Answer `y` to get a ready-made cellar, garden, tunnel, brass key, and gate trigger.

You can also load the checked-in sample project from the BAG menu:

```text
examples/bag/sample.bag
```

## Menu

The menu supports:

- Add area
- List areas
- Add item
- List items
- Add trigger
- List triggers
- Generate adventure
- Save project
- Load project
- Quit

Areas have:

- id
- name
- description
- exits: north, south, east, west, up, down

Items have:

- id
- name
- description
- starting area
- portable flag
- examine text
- use text

Triggers currently model:

```text
using ITEM in AREA opens/closes DIRECTION from AREA to AREA
```

## Generate

Choose menu option `7`.

BAG writes:

```text
examples/bag/generated_adventure.bas
```

Run the generated game with:

```sh
./gbasic examples/bag/generated_adventure.bas
```

The generated game supports:

- `look`
- `north`, `south`, `east`, `west`, `up`, `down`
- `go DIR`
- `take ITEM`
- `drop ITEM`
- `examine ITEM`
- `use ITEM`
- `inventory`
- `help`
- `quit`

## Save And Load

Choose menu option `9` to save the current BAG project. BAG asks for a filename; `.bag` is suggested but not required.

Example:

```text
lantern_room.bag
```

Choose menu option `10` to load a saved project file and continue editing it. Loading restores the project title, areas, items, and triggers.

The project file is generated by gBASIC's `encode(...)` helper and read by `decode(...)`. It is JSON-like gBASIC data, not full JSON. A project has this shape:

```basic
{
    title = title,
    areas = areas,
    items = items,
    triggers = triggers
}
```

Malformed files or unreadable files print a clear load/save message and return to the menu when the runtime error can be handled by `on error resume next`.

## Language Pressure

BAG intentionally exercises:

- arrays of records
- record field access
- helper functions returning records
- menu-driven `input(...)`
- assignment modifiers: `(trimmed)`, `(lowered)`, `(number)`, `(file)`
- file input/output with `read(...)`, `write(...)`, and `append(...)`
- generated gBASIC source code
- `while`, `break`, `continue`, `if`/`else`
- array helpers such as `append`, `remove`, `find`, and `join`
- serialization helpers `encode(...)` and `decode(...)`
